Quick answers for Discord, KanColle live data, and startup issues.

        

          

            
DISCORD CONNECTION

            
Nothing shows up on Discord at all

            
    
              
  • Make sure the Discord desktop app is open.
    • 
              
  • Confirm the Group is enabled and its Process Name exactly matches Task Manager.
    • 
              
  • Check that the active Variant has a real Client ID, not a blank value or YOUR_DISCORD....
    • 
              
  • Check the Activity Log for a connection error.
    • 
            

          


          

            
VARIANTS

            
Two Variants look identical on Discord

            
If both Variants use the same Client ID and neither has a Discord Name, Discord will show the same title. Details and State can still differ.

            
Set a distinct Discord Name for each Variant, or use separate Discord Applications for completely different-looking activities.

          


          

            
CLIENT IDS

            
Can I reuse one Client ID?

            
A Discord Application can hold only one active Rich Presence connection at a time. Reusing a Client ID across Variants is fine when they are not active simultaneously; this app normally displays only one activity at a time.

            
Problems occur when two separate app instances, configs, or Rich Presence tools connect with that same Client ID at once. Use a separate Discord Application for anything that may run concurrently. Creating one takes under a minute; see Quick Start, step 2.

          


          

            
KANCOLLE LIVE DATA

            
Placeholders show a dash, blank, or stop updating

            
    
              
  • Launch Damecon with both --remote-debugging-port=9222 and --remote-allow-origins=*. Missing either flag breaks the connection.
    • 
              
  • Check the Activity Log for “KanColle live-data watcher attached.”
    • 
              
  • Some Admiral fields refresh only after a game load. Reload the KanColle page, or visit the Repair Dock and return to the Port/Home screen once while the manager is running.
    • 
              
  • A literal ? means the name is not recognized; it is different from data that has not arrived yet.
    • 
            

          


          

            
WINDOWS STARTUP

            
Start with Windows stopped working after moving the EXE

            
Untick and re-tick Start with Windows once. This registers the new file location.

          


          

            
EDITING FIELDS

            
Quickly remove all text from a field

            
Click inside the field then press Delete to clear it.

Dynamic Stage Templates

          
Choose which game stages get their own per-variant Details/State template. Global defaults are managed from the Templates page; a variant override here takes precedence. When a stage is set to Use normal template, the global stage default is used when enabled, otherwise the variant's normal Details/State fields are used. When overridden, you can use any built-in or custom placeholder. Blank overridden fields are intentionally allowed, so you can hide Details or State for that stage.
